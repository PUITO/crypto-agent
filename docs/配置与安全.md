# 配置与安全

## 配置分层

1. **`.env` / 环境变量**：启动兜底（LLM URL、同步仓库名、通知渠道等）
2. **Config 服务**：运行时权威；前端「基础设置」分栏编辑
3. **浏览器 Cookie**：仅 **GitHub PAT**（及可选 sync repo 缓存）

## Config 分栏

- 交易 / 策略插件 / 风险 / 数据 / Agent·LLM / 回测与优化 / 服务发现

保存响应中的 `needs_restart` / `restart_required` 会驱动前端提示，并可通过 Ops 一键重启。

## PAT 安全模型（重要）

| 位置 | 是否存放 PAT |
|------|----------------|
| 公开 Git 仓库 | ❌ |
| 服务器 `.env` / 磁盘（默认） | ❌ 不推荐 |
| Config 持久化 JSON | ❌ |
| 用户浏览器 Cookie | ✅ |
| Sync API 请求头 `X-GitHub-PAT` | ✅ 临时使用 |

流程：前端保存 Cookie → 测试 PAT / 拉取·推送持久化时带请求头 → 服务端用完即弃、不写盘。

## 密钥测试（前端「密钥与连接测试」）

| 测试 | 后端 |
|------|------|
| GitHub PAT | `POST /sync/api/v1/test-pat` |
| HF / OpenAI / Ollama / Binance | `POST /config/api/v1/config/test-connection` |
| 通知 | `POST /notify/api/v1/test-channel` |

## 推荐环境变量（无密钥）

见 `.env.example`：`GITHUB_SYNC_REPO`、`NOTIFY_*` 结构说明、服务 URL 覆盖等。

真实 Token 优先：本机环境或用户 Cookie，避免提交到 Git。
