# 快速开始

## 环境要求

- Python 3.11+（推荐 3.12）
- Node.js 18+（前端开发时）
- 可选：Ollama（本地 LLM）

## 安装

```bash
git clone https://github.com/PUITO/crypto-agent.git
cd crypto-agent
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

建议始终设置：

```bash
export PYTHONPATH="$(pwd)/libs:${PYTHONPATH}"
```

脚本已自动导出 `PYTHONPATH`。

## 一键启动（开发）

```bash
./scripts/start_dev.sh          # 全部微服务
./scripts/status.sh             # 查看状态
./scripts/stop_all.sh           # 停止
./scripts/start_dev.sh data-service   # 只启动某一个
./scripts/run_service.sh agent  # 前台跑单个（看日志）
```

验证：

```bash
curl -s http://127.0.0.1:8000/api/v1/health/all | head
curl -s http://127.0.0.1:8001/api/v1/latest_price?symbol=BTCUSDT
```

## 前端

```bash
cd frontend
npm install
npm run dev
# 默认 Vite :5173，通过代理访问 Gateway
```

生产静态资源可构建后挂到任意静态服务器；开发期也可用 `frontend/public-demo.html`。

## 首次使用建议顺序

1. 确认 Data 能拉到 Binance K 线（无需 API Key 的公共接口）
2. 打开 Config / 前端「基础设置」确认交易对与模式
3. Plugin 列表应有 `kdj_rsi_event`
4. 跑一次 Backtest 或在 Chat 里说「跑一下回测」
5. （可选）配置 Ollama 后使用完整 LLM 对话；否则为关键词降级路由
