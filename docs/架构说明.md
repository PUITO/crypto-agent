# 架构说明

## 总览

系统采用 **FastAPI 微服务 + 共享 `libs/common`**。浏览器只访问 **Gateway(:8000)**，由网关转发到各服务。

```
                    ┌─────────────┐
   Browser/App ───► │  Gateway    │
                    │   :8000     │
                    └──────┬──────┘
           ┌───────────────┼───────────────────────────┐
           ▼               ▼                           ▼
      Data:8001       Config:8002                 Agent:8006
      Plugin:8003     Backtest:8004               Chart:8005
      Multi:8007      Ops:8008                    Log:8009
      Sync:8010       Notify:8011
```

## 职责划分

| 服务 | 职责 |
|------|------|
| **Data** | Binance K 线采集、本地存储、数据集构建、HF 可选上传（可降级） |
| **Config** | 唯一配置源；分栏 schema；变更审计；连接测试 |
| **Plugin** | 策略热插拔、信号生成 |
| **Backtest** | 事件合约/合约模式回测 |
| **Chart** | 斐波那契、水平线、趋势线等绘图对象 |
| **Agent** | LLM（Ollama/OpenAI 兼容）+ 工具调用；无 LLM 时降级 |
| **Multi-Agent** | 参数网格搜索 / 矩阵 |
| **Ops** | 启停重启、健康、日志入口（优先 Log Service） |
| **Log** | 集中采集与查询（日志**不**进 Git 同步） |
| **Sync** | `data/persist` ↔ 私有 GitHub 仓（PAT 请求头传入） |
| **Notify** | Webhook / Telegram / EmailJS |
| **Gateway** | 路由、CORS、健康聚合 |

## 持久化约定

统一根目录：`data/persist/`

```
data/persist/
  config/          # 运行时配置 JSON
  market/          # 行情缓存（若迁移至此）
  datasets/        # 训练数据
  chart/
  plugins_state/
  sync_meta/       # 本地同步元数据（一般不同步策略由 Sync 控制）
```

**同步范围**：上述业务数据。**不同步**：`logs/`、进程 PID、日志服务内容。

## 配置流

1. 环境变量：进程启动兜底（`.env`）
2. Config 服务：运行时权威来源
3. 其它服务可用 `common.remote_config.RemoteConfigClient` 拉取
4. 变更分类：热更新 vs 需重启（前端提示 + Ops 一键重启）

## 安全相关设计

- GitHub **PAT 默认不落服务器盘**，浏览器 Cookie → 请求头 → Sync
- 公网部署时用户各自持有 PAT，降低整站被盗用风险
- 敏感字段在 Config `public_view` 中脱敏

## 前端结构

- 用户端：图表 + Chat + 模式/设置 Dialog + 交易信号历史 + 统计
- 设置页：Config 分栏 + 密钥测试面板
- 健康运维：微服务生命周期与日志
- 训练端（规划/部分能力）：回测与参数评测，可复用 Backtest/Multi API
