# 微服务手册（摘要）

各服务均提供 `GET /health` 与 `GET /docs`。生产经 Gateway 访问时前缀为 `/data`、`/config` 等。

## Gateway `:8000`

- `GET /api/v1/health/all` — 聚合健康
- 代理：`/data/*` `/config/*` `/plugin/*` `/backtest/*` `/chart/*` `/agent/*` `/ops/*` `/log/*` `/sync/*` `/notify/*`

## Data `:8001`

- `GET /api/v1/latest_price`
- `GET /api/v1/klines`
- `POST /api/v1/fetch` — 手动采集
- `POST /api/v1/dataset/build` — 构建数据集（HF 无 Token 则本地降级）
- 定时：默认 5m 增量

## Config `:8002`

- `GET /api/v1/config` — 配置（默认脱敏）
- `GET /api/v1/config/schema` — 前端分栏
- `POST /api/v1/config/preview|apply` — 预览/应用（含 `needs_restart`）
- `POST /api/v1/config/test-connection` — 测试 binance/hf/ollama/openai

## Plugin `:8003`

- `GET /api/v1/plugins`
- `POST /api/v1/plugins/{name}/signals`

## Backtest `:8004`

- `POST /api/v1/backtest` — 回测结果含胜率、回撤等

## Chart `:8005`

- `POST /api/v1/drawings/fibonacci` 等
- `GET /api/v1/drawings`

## Agent `:8006`

- `POST /api/v1/chat` — `{ message, session_id }`

## Multi-Agent `:8007`

- `POST /api/v1/optimize` — 参数网格

## Ops `:8008`

- `GET /api/v1/services`
- `POST /api/v1/services/{name}/start|stop|restart`
- `GET /api/v1/logs/{name}`

## Log `:8009`

- `POST /api/v1/logs` / `batch`
- `GET /api/v1/logs` / `{service}/tail`

## Sync `:8010`

- 请求头：`X-GitHub-PAT`、`X-Sync-Repo`（可选，覆盖环境变量中的 repo）
- `POST /api/v1/test-pat` | `pull` | `push`
- `GET /api/v1/status` | `files`
- 定时默认 `0 12 * * *`（无服务端 PAT 时定时任务会跳过/失败，属预期）

## Notify `:8011`

- `POST /api/v1/notify`
- `POST /api/v1/test-channel`
- 渠道：`webhook` / `telegram` / `emailjs`
