# Android App 界面设计（android-app 分支）

源码目录：`android/`（与 [crypto-app](https://github.com/PUITO/crypto-app) 对齐并可持续同步）

## 信息架构

```
启动 → 首次引导(条数/默认周期) → 主界面
                              ├─ 配置列表 → 配置编辑
                              └─ 设置
```

## 主界面（严格分区）

```
┌─────────────────────────────────────────────┐
│ Header                                      │
│  币种▼   周期▼(5m/10m/30m/1h)   配置  设置  │
├─────────────────────────────────────────────┤
│ 策略状态 + 启动/停止 + 后台监控 Chip + 刷新  │
├─────────────────────────────────────────────┤
│ 图表（X/Y 轴、网格、双指缩放/平移、B/S）      │
├─────────────────────────────────────────────┤
│ 统计（全部模拟成交，非仅列表 5 条）           │
├─────────────────────────────────────────────┤
│ 交易历史 Table（默认 5 条 / 共 N 笔）         │
└─────────────────────────────────────────────┘
```

### 视觉规范

| 元素 | 规范 |
|------|------|
| 背景 | `#0B0E11` / 卡片 `#12161C` |
| 主色 | `#F0B90B`（Binance 黄） |
| 涨/买 | `#0ECB81` |
| 跌/卖 | `#F6465D` |
| 轴/次要文字 | `#848E9C` |
| 图表 | 左 Y 价格、下 X 时间、网格、双击重置 |

### 配置编辑

- 标题
- 买入区：多条件 OR，指标/比较/阈值，＋添加
- 卖出区：同上
- 列表仅允许一套「启用」

### 设置

- Binance Base URL、默认条数、默认币种、默认周期

## 包名

- 本分支构建：`com.puito.cryptoagent`（debug 后缀 `.debug`）
- 独立仓库 crypto-app：`com.puito.cryptoapp`（可并存安装）
