HiBT Token 助手

Crypto Agent · 手机真实下单配置

登录 hibt.com 后，点击书签即可自动抓取会话 Token，填到 App「下单」页。

风险提示：Token 等同已登录会话，勿发到公开群/仓库。本工具仅在你本机浏览器运行，不上传服务器。 HiBT 无官方第三方量化 API，自动化有封号与资金风险，后果自负。

① 安装书签（电脑 Chrome / Edge）

把下面按钮拖到浏览器书签栏（或右键 → 将链接添加为书签）：

HiBT取Token

若拖拽无效：书签管理 → 添加书签 → 网址粘贴下方「书签源码」全文（以 javascript: 开头）。

② 使用步骤

  1. 电脑打开并登录 https://hibt.com
  2. 进入事件合约页面，确认能看到行情
  3. 点击书签栏 HiBT取Token
  4. 页面会出现浮层：自动扫描 localStorage / Cookie，并拦截接下来约 20 秒的 API 请求头
  5. 在官网随意点一下刷新/持仓，让接口发出请求（便于抓到 Authorization）
  6. 在浮层点「复制」→ 打开手机 App → 下单页粘贴 → 测试连通性

手机运行监控时不需要一直开着电脑浏览器；Token 过期后再取一次即可。

③ 填到 App 的字段

  • API Base：一般 https://api.hibt0.com
  • Authorization
  • x-auth-token
  • v（若 URL 带 ?v=）
