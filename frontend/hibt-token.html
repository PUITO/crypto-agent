HiBT Token 助手（V2）

对齐主流抓包书签逻辑：监听期权/事件合约 API，提取 x-auth-token、浏览器指纹头、bgetKey/bgetId、API Base。

风险：Token = 登录会话。勿公开分享。本页仅生成本地书签，不上传服务器。 HiBT 无官方量化 API，真实下单风险自负。

① 安装书签

将按钮拖到书签栏：

HiBT取Token·CA

无效时：添加书签 → 网址粘贴下方「书签源码」全文。

② 使用

  1. 登录 HiBT 相关站点（如 hibt.com、web.dutbgwv.online 等已登录页）
  2. 打开期权 / 事件合约 / 订单 / 首页
  3. 点击书签 HiBT取Token·CA → 提示「监听已开启」
  4. 再点一下下单区、订单列表或刷新，触发 API
  5. 抓到后自动弹出可复制内容 → 填入 App「下单」页

第二次点书签：若已有缓存包会直接再导出；否则提示继续操作页面。

③ 对应 App 字段

  • API Base → 如 https://api-ws.taichuwuji.com
  • x-auth-token → 主会话（优先）
  • Authorization → 可与 token 相同或留空
  • bgetKey / bgetId（若 App 已支持）
