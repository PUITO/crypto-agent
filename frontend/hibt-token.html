HiBT Token 助手

对齐「币安精灵」类抓包书签逻辑：在已登录的 HiBT 镜像站拦截 API 请求头，生成手机 App 可用配置。

Token 等同登录态，勿外传。仅本机运行。非官方接口，风险自负。

① 安装书签

将按钮拖到书签栏：

HiBT取Token·CA

支持域名含：hibt / bget / taichuwuji / dutbgwv / s0e9tu 等。

② 使用

  1. 电脑登录 HiBT 官网或当前可用镜像（事件合约页）
  2. 点击书签 HiBT取Token·CA
  3. 再点一下「期权/订单/首页」触发 API
  4. 抓到后自动打开导入页并复制 JSON；粘贴到 App「下单」或在导入页对照填写

③ App 字段对应

  • token → x-auth-token / Authorization
  • apiBaseUrl → API Base（常见 api-ws.taichuwuji.com）
  • bgetKey / bgetId
  • langCode / clientType（web=1 / h5=2）
