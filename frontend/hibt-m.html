① 手机 Chrome 安装书签

  1. 复制下方书签地址（整段 javascript:...）
  2. Chrome → 星标收藏任意页 → 编辑书签
  3. 名称填 HiBT取Token，网址整段替换为刚复制的 javascript
  4. 打开并登录 HiBT（事件合约页）→ 地址栏旁或书签里点 HiBT取Token
  5. 再点一下订单/首页触发接口，抓到后会跳回本站导入页并写入本地
打开 HiBT
